Редактируемый шаблон видеохронологии 1920 × 1080: схема, видеоврезка, события, контекст, стенограмма, шкала и часы. Демонстрационные события вымышлены.

## Запуск

В каталоге проекта:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте приложение через доступный интерфейс среды или откройте `index.html` непосредственно в современном браузере. Сборка и установка зависимостей не нужны. Внешние сервисы и ключи не используются.

## Работа

- В «Событиях» укажите секунды от начала ролика, описания и реплики. События выводятся по времени, независимо от порядка в редакторе.
- В «Оформлении» задайте начальные часы, длительность (5–3600 секунд), акцентный цвет и контекст. Можно загрузить схему и локальное видео во врезку. Видео начинается вместе с хронологией, без звука.
- Воспроизведение, перемотка и скорость управляют предпросмотром. При экспорте скорость всегда 1×.
- «Сохранить проект» скачивает JSON с настройками и изображением; видео в JSON не включается. «Открыть проект» восстанавливает настройки. Автосохранение использует localStorage; при переполнении скачайте JSON.
- «Экспорт видео» записывает WebM 1920 × 1080 / 30 кадров/сек. в реальном времени, без аудио. Держите вкладку открытой и активной. Повторное нажатие завершает запись раньше. Реальная частота кадров зависит от производительности устройства.
- Текущий шаблон перемещает два демонстрационных маркера по схеме. Для конкретного события траектории и точки подготавливаются отдельно.

## MP4

После экспорта можно преобразовать файл установленным FFmpeg:

```sh
ffmpeg -i chronicle.webm -c:v libx264 -crf 20 -pix_fmt yuv420p -movflags +faststart chronicle.mp4
```

Записи и изображения обрабатываются локально. Файлы на сервер не отправляются. Сторонних шрифтов и библиотек нет.
